# Security policy

Flickbar runs with Accessibility permission and watches trackpad input, so security reports are taken seriously.

## Supported versions

Only the [latest release](https://github.com/flickbar/flickbar/releases/latest) receives fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/flickbar/flickbar/security/advisories/new).

Include what you found, the Flickbar version and macOS version, and steps to reproduce. You'll get a reply
within a few days; this is a one-person project, so please be patient. Once a fix is released you'll be
credited in the release notes unless you prefer otherwise.

Examples of in-scope problems: reading or injecting input outside Flickbar's gestures, an update that
installs without a valid signature, or any way to make Flickbar act on windows without the user's gesture.
